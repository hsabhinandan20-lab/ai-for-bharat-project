# AI-Based Learning Assistant for Rural Students

## Overview
This project proposes an AI-powered learning assistant designed to help students understand subjects easily using simple language.

## Problem
Many students, especially in rural areas, lack access to quality educational support.

## Solution
An AI assistant that answers questions, supports local languages, and works with low internet usage.

## Files in this Repository
- requirements.md – Describes project goals and features
- design.md – Explains the system design and workflow
